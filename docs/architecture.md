# 同步架构

## 0.2 共享工作区

一个 VS Code 文件夹关联一个服务器地址和工作区 ID。关联保存在 VS Code 工作区状态中，令牌保存在 VS Code SecretStorage。项目重新打开后，扩展读取这些信息并恢复会话。原生编辑通过 VS Code 保存，外部工具可直接读写磁盘文件。协作者的设备通过服务端交换文件版本。

0.2.2 的图形连接窗口把服务器地址、工作区 ID 和令牌交给同一加入流程。填写 `wss://` 地址时，工作区模式通过相同主机的 HTTPS 接口同步：`GET /workspace/manifest` 列出文件版本，`GET`、`PUT` 和 `DELETE /workspace/file` 分别下载、提交和删除文件。这些请求使用 Bearer 令牌。局部提交带 `If-Match` 版本条件。

服务器按路径保存文件版本、SHA-256、原始字节和删除标记，使用 SQLite WAL 提交。客户端保存上次确认的版本与文本基线。上传和删除携带已知版本，服务端核对后提交。下载核对长度和 SHA-256。客户端依据共同基线合并非重叠的文本改动，保留重叠或二进制冲突。文件接收写入前先保存本地投影意图，重启后可核对并继续处理。

0.2 工作区按文件版本自动同步。下面记录 0.1 单文件模式的 Yjs 增量通道。

## 0.1 单文件模式

```text
VS Code 原生 .tex 缓冲区
   │ 文档编辑事件 / 远端增量投影
本地 Y.Text (content)
   │ Hocuspocus / WebSocket
服务端 Y.Doc（永久 UUID）
   │ 提交快照
SQLite WAL（同步级别 FULL）
   │ GET /persisted?document=<UUID> 返回快照摘要
VS Code 验证当前协作状态是否已经提交
```

Phase 1 在 `127.0.0.1` 上运行。服务端仅允许 IPv4 或 IPv6 回环绑定，拒绝带 `Origin` 的 WebSocket 升级。两客户端打开各自目录里的同名空白文件，用同一个文档 UUID 及测试令牌连接。服务端新文档从空状态开始。文件内容一致时，进入实时同步。已有文件和共享版本不同则需要显式选择，连接前先保留本地版本。

对本地输入或通过 VS Code 编辑 API 发出的编辑，扩展以文档的改动范围更新 `Y.Text`。编辑前的 UTF-16 偏移与 VS Code 文档偏移一致。远端更新经过单独的来源标记投影到编辑器，避免把回写重复提交。保存编辑器文件使用 VS Code 的保存动作。界面中的 Saved 专指对应的协作状态已在服务端提交，可与编辑器标签上的磁盘保存标记分别查看。

断网时，已连接客户端继续修改本地 Yjs 状态。恢复网络后 provider 交换二进制增量。自 0.1.2 起，`LSW: Prepare AI Edit` 记录编辑器、磁盘及服务端一致的快照摘要。外部写入后，扩展等 VS Code 重新加载磁盘内容，向服务端提交带摘要前提的替换请求。服务端在同一事件循环轮次校验当前版本、应用文本差异并提交 SQLite 快照。其他客户端接收同一份增量。基线不匹配时保留副本并显示冲突。

持久化入口是单进程 SQLite。保存后计算完整二进制状态的 SHA-256 并通过独立接口读回。存在未存盘编辑、快照仍旧或确认接口不可用时，客户端继续显示当前同步状态。持久化和多人编辑分别验证。一个进程重启后从 SQLite 加载快照，多个进程共享同一个数据库会需要额外的跨进程一致性设计。

## 后续方向

现有工作区按路径区分文件，同一工作区使用共享令牌。独立成员身份、按成员撤销授权和基于项目快照的远程编译可以分别扩展。

## 接口

| 接口 | Phase 1 用途 |
| --- | --- |
| WebSocket `ws://127.0.0.1:1234/` | 标准 Hocuspocus provider，文档名为 UUID，令牌校验 |
| `GET /healthz` | 进程健康探测 |
| `GET /persisted?document=<UUID>` | Bearer 令牌鉴权，返回已提交快照的 `sha256` 和 `updatedAt` |
| `POST /disk-edit?document=<UUID>` | Bearer 令牌鉴权，`If-Match` 匹配已提交快照摘要后应用外部写入。成功时返回已提交的 Yjs 状态，版本已变更时返回 412 |

初始文档 ID 为 `11111111-1111-4111-8111-111111111111`，文本键为 `content`。可通过 `LSW_DOCUMENT_ID` 为独立测试实例指定另一个 UUID。共享令牌适用于本地验证，生产发布前需要实现成员身份、权限和单成员撤销。
